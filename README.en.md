# AI Markdown Document Organizer

English | [简体中文](./README.md)

Immersive WYSIWYG editing + AI-powered document refinement, with a single shared core covering **iOS / Windows / Linux (including macOS)**.

- Design docs: [docs/design-review.md](docs/design-review.md) · [docs/enhanced-design.md](docs/enhanced-design.md) (Chinese)
- Test report: [docs/platform-test-report.md](docs/platform-test-report.md) (Chinese)
- Changelog: [CHANGELOG.md](CHANGELOG.md)

## Features

| Module | Capabilities |
|---|---|
| Editing | Milkdown WYSIWYG live rendering, full GFM syntax, outline navigation, stats, unlimited undo, **click anywhere in the editor to place the cursor** |
| AI Refinement | Hideable panel (✨ / Ctrl+Shift+2); **dual trigger: floating toolbar on selection / whole-document processing**; 20 built-in commands + custom commands; long-text chunking; **results applied via preview dialog only (source untouched during processing)**; editor auto-locked while AI is running |
| Persona | Global role setting (e.g. "a writer with 10 years of experience") injected into every AI request; 4 preset templates |
| Models | OpenAI-compatible endpoints (DeepSeek / OpenAI / Kimi / GLM / Qwen / local Ollama), multiple profiles with switching and connectivity test |
| Files | Chinese native menu bar (New / Open / Save / Save As / Export), recent files, autosave, rolling backups before AI runs, external-change conflict detection (desktop) |
| Export | **MD / TXT / HTML / PDF / DOCX / PNG** with per-format options (PDF paper · orientation · margins; PNG width · scale; HTML source embedding; DOCX font size) |
| Tables | Insert a table of any size at the cursor (menu / context menu / shortcut ⌘/Ctrl+Alt+T, customizable in settings), with a row-column dialog and GFM preview |
| Title Bar | Dynamic: saved → document name; unsaved → "Untitled"; modified → name with a trailing `*` |
| Settings | **Dedicated settings page** (editor/settings view switch + back), four groups: AI models / privacy / editor / appearance |
| Themes | Light / dark / sepia / paper / ink / follow system + font size and line-height customization |
| Security | OS-level key encryption (safeStorage), privacy mode (local endpoints only), pre-send redaction, DOMPurify XSS protection, hardened Electron sandbox |

## Tech Stack

Vue 3 + TypeScript + Pinia + Vite · Milkdown (WYSIWYG engine) · Electron (desktop shell) · Capacitor 7 (iOS shell)

Platform differences are unified behind `src/renderer/lib/platform/` (a `PlatformAdapter` interface with three implementations).

## Getting Started

```bash
cd src
npm install

# Unit tests (106 tests)
npm test

# Desktop development (Windows/Linux/macOS, launches Electron automatically)
npm run dev

# Browser-only development (AI works only with CORS-friendly endpoints, e.g. local Ollama)
npm run dev:web

# Type checking / builds
npm run typecheck
npm run build:web        # outputs dist/ (also the iOS webDir)
npm run build:desktop    # outputs dist/ + dist-electron/
```

### Desktop Installers (run on the target platform)

```bash
npm run build:win     # NSIS installer → src/release/ (run on Windows)
npm run build:linux   # AppImage + deb (run on Linux)
npm run build:mac     # dmg (run on macOS)
```

### iOS

```bash
cd src
npm run ios:sync      # build web assets and sync into the Xcode project
npm run ios:open      # open Xcode (choose a device/simulator and run)
# Command-line simulator build verification:
cd ios/App && pod install && xcodebuild -scheme App -sdk iphonesimulator build
```

iOS highlights: app Documents folder interoperable with the Files app (`UIFileSharingEnabled`), native HTTP (bypasses WKWebView CORS), system share-sheet export, dark mode and safe-area support.

## AI Configuration

After launch, open Settings → AI Models: fill in the endpoint (OpenAI-compatible `/v1`), API key (stored with OS encryption), and model name, then click "Test connectivity". Preset templates are in `config/ai-providers.example.json`. A global persona (e.g. "a writer with 10 years of experience") can be configured under Settings → AI Models → Persona and applies to all AI processing.

Local models (recommended for privacy):

```bash
ollama serve   # endpoint http://localhost:11434/v1, e.g. model qwen2.5
```

## Requirements

- Node ≥ 20, npm ≥ 10
- Desktop: standard build toolchain per platform (Windows: VS Build Tools optional; Linux: libsecret, libnss3 and other Electron deps)
- iOS: macOS + Xcode ≥ 16 + CocoaPods (`brew install cocoapods`)

## Known Limitations (v0.2)

- The volume hosting this project restricts directory deletion for node fs; Vite is configured with `emptyOutDir: false`, so stale hashed assets from repeated builds must be cleaned manually
- In browser fallback mode, AI requests are subject to CORS restrictions (desktop/iOS go through the native layer and are unaffected)
- On iOS, PDF export falls back to sharing HTML (save as PDF via system print), DOCX goes through the share sheet, and PNG is desktop-only
- On iOS, API keys are stored in sandboxed Preferences; Keychain plugin upgrade is planned for v2 (see enhanced design §7.1, Chinese)
